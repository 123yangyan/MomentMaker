## 一、产品背景与目标

### 1.1 背景

用户在漫展、演唱会等线下活动现场拍摄了大量照片，但受限于设计能力与工具门槛，往往无法将这些素材快速整理成**可分享的精美内容**，也无法生成有纪念价值的实体物料（如吧唧、明信片、钥匙扣等）。

### 1.2 产品目标

- **降低创作门槛**：通过 AI 自动完成多图评分、候选图筛选和海报生成，让零设计能力的用户也能生成精美成品。
- **提升传播裂变**：输出内容天然适配社交分享，配套"发布广场"功能，形成 UGC 社区效应。
- **快速验证 MVP**：本次黑客松以 Web 端为主，优先打通完整用户流程，保证现场演示顺畅。

### 1.3 目标用户


| 用户类型    | 特征描述                   |
| ------- | ---------------------- |
| 漫展参与者   | 热爱 Cosplay，有强烈的内容分享欲望  |
| 演唱会粉丝   | 记录现场感动时刻，希望产出与众不同的应援物料 |
| 普通活动参与者 | 想留存活动记忆，但设计能力有限        |

## 二、产品开发标准（MVP 验收指标）


| 指标          | 具体要求                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 首屏/广场页加载    | Web 端扫码/打开链接，首屏渲染及广场页样例图加载总时间 **≤ 1.5 秒**                              |
| 生成过程体验      | 云端处理（多图评分、筛选、合成）期间，前端必须有**动态 Loading 进度条**或**有趣的生成动画**，绝不能出现假死或纯白屏       |
| 移动端兼容性      | 必须在 iPhone（Safari）、主流 Android 微信内置浏览器及 iPad/平板上 100% 布局兼容，无横向滚动条、无按钮遮挡 |
| Mock 预设演示模式 | 必须内置"演示暗门"或"默认样例选项"，断网/服务器异常时读取本地/CDN 缓存静态数据，**0.5 秒极速伪实时生成**          |
| 静态资源部署      | 广场页示范图片与前端代码部署在 CDN，确保评委扫码瞬间加载完成                                       |

## 三、产品核心逻辑



### 3.1 整体流程

```
用户进入广场页 → 点击"创作我的" → 上传多张图片
→ 选择风格模板 → AI 多图评分并选出 3～4 张 → 用户在 P4 调整选择与顺序 → 生成海报 → 预览导出 → 发布至广场
```



### 3.2 AI 处理核心能力


| 能力         | 说明                              |
| ---------- | ------------------------------- |
| 多图评分与筛选    | 对全部上传图片评分，按稳定规则选出 3～4 张候选图      |
| 候选图确认      | 用户在 P4 从评分结果中确认 3～4 张图片并调整合成顺序     |
| 成品图生成      | 将确认图片与所选模板、风格和物料参数生成最终成品          |
| 颜值匹配玩法（可选） | "测测你的颜值适配哪首诗"等趣味互动，增加用户留存与传播点   |




### 3.3 模板体系

**模板类型**（3 种）：

- **连环画**：多格漫画布局，适合漫展 Cosplay 记录
- **故事地图**：时间线/地图路线感，适合活动旅程回顾
- **记录册**：相册翻页风格，适合演唱会珍藏纪念

**视觉风格**（3 种）：

- **二次元**：插画感、高饱和度、日系动漫色调
- **演唱会/赛博**：霓虹感、深色背景、电子朋克氛围
- **普通写实**：简洁白底、杂志排版风格

**实体物料形态**（3 种，单选）：

- 吧唧（徽章）
- 明信片
- 钥匙扣

## 四、产品页面详细规划



### P1 — 广场 / 社区展示页（首页）

**路由**：`/`
**目标**：用户扫码进来第一眼看到精美内容，激发创作欲望

#### 页面模块


| 模块        | 内容描述                                                    |
| --------- | ------------------------------------------------------- |
| 顶部 Banner | 产品 Logo + 名称 + Slogan（"把你的故事，变成传得出去的记忆"）+ "立即创作" CTA 按钮 |
| 作品瀑布流     | 3 列卡片布局，展示用户生成的电子成品缩略图 + 实体物料效果图（吧唧/明信片/钥匙扣）            |
| 作品卡片      | 封面图 + 类型标签（如"连环画 · 二次元"）+ 用户昵称 + 点赞数                    |
| 作品全屏预览    | 点击卡片后弹出 Lightbox，展示完整电子成品 + 对应实体物料效果图                   |
| 底部浮动按钮    | "+创作我的" 固定在右下角，任何滚动位置均可见                                |




#### 数据与性能

- Mock 预置 12 张精美示范作品图，存放于 CDN
- 图片懒加载，首屏仅渲染前 6 张
- 广场页作品数据支持真实 API 拉取（降级到 Mock）

---



### P2 — 素材上传页

**路由**：`/upload`
**目标**：最低门槛，用户 30 秒内完成素材提供

#### 页面模块


| 模块      | 内容描述                                                       |
| ------- | ---------------------------------------------------------- |
| 上传区域    | 拖拽 or 点击上传，只接受图片文件，最多 20 张                                  |
| 文本补充    | 可选输入框，用户描述本次活动感受或关键词（用于 AI 风格增强）                           |
| 上传预览列表  | 缩略图 Grid 展示已上传素材，支持单张删除                                    |
| AI 识别进度 | 上传完成后显示"AI 正在识别素材..."带动效的进度条（伪进度，防白屏假死）                    |
| 演示暗门    | 页面底部显示"使用样例素材体验 →"，点击直接载入预置 Mock 素材包，跳过上传步骤，0.5s 内进入下一步    |




#### 边界条件

- 单张图片大小限制：≤ 10MB
- 未上传素材时"下一步"按钮禁用，并给出友好提示
- 上传失败时提示"网络不稳定，请重试"或自动降级至演示模式

---



### P3 — 风格模板选择页

**路由**：`/template`
**目标**：帮用户在 10 秒内选定视觉风格，并触发 AI 生成

#### 页面模块


| 模块     | 内容描述                                             |
| ------ | ------------------------------------------------ |
| 模板类型选择 | 3 张大卡片（连环画 / 故事地图 / 记录册），含效果预览封面图，点击高亮选中         |
| 风格选择   | 3 个样式标签（二次元 / 演唱会赛博 / 普通写实），选中后实时刷新右侧预览          |
| 物料形态预选 | 3 个图标按钮（吧唧 / 明信片 / 钥匙扣），只能单选                     |
| 实时预览区  | 右侧（或下方）展示当前选择组合的模板效果预览缩略图（本地 Mock 图）             |
| 开始生成按钮 | 点击后调用后端 API 触发生成任务，进入生成等待状态（跳转 P4，页面内显示 Loading） |




#### 交互细节

- 所有选项均有默认值（默认：连环画 + 二次元 + 吧唧），确保用户可以直接点击"开始生成"
- 生成按钮文案在点击后变为"生成中...✨"，禁止重复点击

---



### P4 — 候选图片确认与排序页（核心亮点）

**路由**：`/editor`
**目标**：展示 AI 多图评分结果，并让用户确认用于生成海报的 3～4 张图片及其顺序

#### 页面模块


| 模块          | 内容描述                                                    |
| ----------- | ------------------------------------------------------- |
| 评分 Loading | 轮询任务状态，展示“AI 正在评分与筛选图片...”及 0～100% 真实任务进度             |
| 候选图片区      | 展示全部上传图片、评分摘要及默认入选的 3～4 张图片                         |
| 图片操作        | 点击选中或取消；用户可以从未入选图片中替换候选图                          |
| 排序调整        | 拖拽已选图片调整海报生成时的输入顺序                                |
| 数量校验        | 只能提交 3 张或 4 张互不重复且属于当前任务的图片                         |
| 生成成品按钮      | 先保存选择和顺序，再调用最终海报合成 API；提交后禁止重复点击                  |




#### Mock 演示方案

- 本地预置一组带评分结果的候选图片，Mock 模式下直接展示，0.5s 内呈现完毕
- Mock 模式仍需遵守选择 3～4 张和排序规则，最终展示预置海报

---



### P5 — 预览导出与发布页

**路由**：`/preview`
**目标**：给用户惊喜感和成就感，并驱动社交分享传播

#### 页面模块


| 模块      | 内容描述                                   |
| ------- | -------------------------------------- |
| 成果展示区   | 最终电子成品全屏展示，支持左右翻页（多页成品）                |
| 实体物料效果图 | 展示成品贴合到吧唧/明信片/钥匙扣实体样机上的 3D 效果图         |
| 操作按钮组   | 三个操作："发布至广场" / "保存到本地" / "再改一改（返回 P4）" |
| 发布弹窗    | 发布成功后显示弹窗：生成分享二维码 + "复制链接" + "长按保存海报"  |
| 本地导出    | 将成品通过 Canvas API 导出为 PNG 图片，触发浏览器下载    |




#### 分享裂变设计

- 分享链接打开后直接进入广场页，并高亮展示该作品
- 海报模板内嵌产品名称与二维码，引导扫码进入产品

## 五、用户完整操作流程图

```
[扫码/打开链接]
       ↓
[P1 广场首页]
  - 浏览他人作品
  - 点击"立即创作" / "+创作我的"
       ↓
[P2 素材上传页]
  - 上传多张图片
  - 或点击"使用样例素材"（演示暗门）
       ↓
[P3 模板选择页]
  - 选择模板类型 + 视觉风格 + 物料形态
  - 点击"开始生成"
       ↓
[P4 候选图片确认与排序页]
  - 查看多图评分和默认入选结果
  - 确认或替换 3～4 张图片并拖拽排序
  - 点击"生成成品"
       ↓
[P5 预览导出页]
  - 查看最终成品
  - 发布至广场 / 保存本地 / 分享海报
       ↓
[返回广场页，新作品出现在瀑布流中]
```

## 六、非功能性需求



### 6.1 性能

- 首屏白屏时间 ≤ 1.5s（CDN 加速 + 代码懒加载）
- AI 生成任务超时设定：60s，超时后自动降级展示 Mock 结果
- 所有静态资源（图片、字体、JS）均部署至 CDN



### 6.2 兼容性


| 平台              | 要求               |
| --------------- | ---------------- |
| iPhone Safari   | 完整功能可用，布局无错位     |
| Android 微信内置浏览器 | 完整功能可用，上传/下载功能正常 |
| iPad / 平板       | 布局自适应，无横向滚动条     |
| PC 浏览器（Chrome）  | 完整功能可用（黑客松评审用）   |




### 6.3 容错与降级


| 场景     | 降级方案                         |
| ------ | ---------------------------- |
| 网络断开   | 自动切换至 Mock 演示模式，功能完整可用       |
| 后端服务异常 | 前端捕获错误，展示友好提示 + "使用演示数据继续"按钮 |
| 上传失败   | 弹出提示"上传失败，是否使用样例素材？"         |
| 生成超时   | 60s 后展示超时提示 + 自动展示 Mock 成品   |
