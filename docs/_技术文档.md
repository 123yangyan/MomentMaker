# MomentMaker 技术实现总体思路

## 核心原则

黑客松时间紧，优先选**最熟悉、最少踩坑**的技术，保证能跑通完整流程。

---

## 技术栈选型

**前端（连胜）**

- React \+ Vite \+ TypeScript

- Tailwind CSS（快速写响应式布局，移动端适配必须）

- Axios（HTTP 请求）

- 通信方式：调用后端 REST API \+ 监听 SSE/轮询获取进度

**后端（杨洋）**

- Python \+ FastAPI（轻量、自带接口文档、与 Python AI 模块天然同语言）

- SQLite（黑客松够用，零配置）

- Python\-multipart（处理文件上传）

- 本地磁盘存储上传文件和生成结果图

**Python AI 服务（杨帆）**

- 不单独起服务，以**模块**形式集成进后端 FastAPI 项目

- GLM-4.5V（图片质量与人物清晰度评分）

- GLM-4.5V（对全部上传图片评分，稳定选出 3～4 张候选图）

- Pillow（图片合成、模板叠加渲染）

- 杨帆只需维护 `ai/` 目录下的模块，杨洋调用即可

## 三端职责边界（一句话版本）

- **前端**：只负责页面展示、用户交互、调接口、展示 Loading 动画；不做任何 AI 运算

- **后端**：接收前端请求、存文件、调 AI 模块、存数据库、返结果；是协调中心

- **Python AI**：只管"输入多张图片 → 评分并选出 3～4 张 → 输出生成结果图"，不关心 HTTP、不关心数据库

---

## 前后端通信协议

所有接口统一前缀 `/api`，返回 JSON。

**核心接口清单**

- `POST /api/uploads` — 上传图片，返回上传批次与文件 ID 列表

- `POST /api/tasks` — 提交作品名称、模板、风格、单选物料与文件 ID，创建任务并返回 `task_id`

- `GET /api/tasks/{task_id}` — 前端每 2 秒轮询一次，返回状态、进度、候选图片和结果 URL

- `POST /api/tasks/{task_id}/selection` — P4 保存用户确认的 3～4 张图片及合成顺序

- `POST /api/tasks/{task_id}/compose` — P4 确认后触发最终成品图生成

- `GET /api/works` — 获取广场作品列表（支持分页）

- `POST /api/works` — 发布作品到广场

**进度同步方式**：前端每 2 秒轮询一次 `GET /api/tasks/{task_id}`。比 WebSocket 简单，黑客松够用。

## 关键数据格式约定（前后端共同遵守）

**任务状态返回格式**

```JSON
{
  "task_id": "abc123",
  "status": "processing",
  "progress": 60,
  "selected_files": [
    { "file_id": "file_1", "preview_url": "/files/file_1/preview", "rank": 1 }
  ],
  "result_url": null
}
```

**作品数据格式**

```JSON
{
  "work_id": "work_001",
  "cover_url": "/files/cover.jpg",
  "template": "comic",
  "style": "anime",
  "nickname": "游客用户",
  "likes": 42
}
```

## Mock 演示模式（非常重要！）

PRD 要求断网/服务异常时 0\.5s 极速响应。实现方案：

- **前端内置** `mock/` 目录，存放预置的 JSON 数据和图片 URL（指向 CDN）

- 每次调 API 前先检测，如果接口超时（\>3s）或返回 5xx，自动切换到 Mock 数据

- 后端也可内置 `?demo=true` 参数，直接返回预设 Mock 响应（不走 AI 运算）

## 开发顺序建议

1. **第一步**：后端先把 `/api/uploads` 和 `/api/works` 接口跑通（杨洋），前端先做 P1 广场页静态页面（连胜）

2. **第二步**：杨帆完成 `score_images.py` 多图评分模块，杨洋接进 `/api/tasks` 流程

3. **第三步**：前端接入真实 API，替换 Mock 数据，联调 P2→P3→P4 完整流程

4. **第四步**：P5 导出页 \+ 广场发布 \+ 演示 Mock 降级逻辑兜底
